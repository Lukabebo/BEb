# Starlit Caverns

A lightweight text adventure you can play in the terminal. Explore a small cavern, collect artifacts, avoid hazards, and reach the exit with at least two treasures.

## Playing

```bash
python -m game.cli
```

Commands:
- `n`, `s`, `e`, `w` — move north/south/east/west
- `rest` — wait a turn
- `map` — show explored tiles
- `help` — view commands
- `quit` — exit the session

## Tests

Run the basic tests with `pytest`:

```bash
pytest
```
